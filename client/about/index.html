Meet HANNAH, an AI companion that works for you

HANNAH talks with you, remembers what you ask it to, and gets real work done: a team of AI agents for hard questions, and workflows that run on their own. It works with 20 AI providers or with models on your own hardware, and nothing changes on your device or data without your yes.

What it does

One companion for conversation, work and automation

Any model, picked for you

Groq, OpenAI, Anthropic, Gemini and 11 more cloud providers with your own key, or Ollama, LM Studio, llama.cpp, vLLM, WebLLM and on-device models. Auto routing picks one per message.

A team of agents

Research, Coding, Memory and Tasks specialists work in parallel and the result is checked before you see it. In the desktop app they can work in folders you share.

Visual workflows

Build automations on a canvas: schedules, new email, webhooks and file uploads start AI steps, conditions and integrations on HANNAH's server, with a record of every run.

Memory you own

See, edit, export or delete everything HANNAH remembers. Only memories related to a message are sent with it, and sensitive ones go only to local models.

Voice and presence

Talk in English, Hindi or Marathi, say “Hey HANNAH” hands-free, and watch a real-time 3D avatar react to the mood of each reply.

Everywhere you are

The web app and PWA, desktop apps for macOS, Windows and Linux, and Android. Sign in and your memories, tasks and approvals follow you between devices.

Each feature on the home page is labelled Available, Beta or Coming. Features still being built aren't presented as working.

Your data, your rules

Choose how HANNAH processes your messages

With a cloud model, your message goes through the HANNAH server to the provider you chose, and that provider's privacy and retention terms apply. In Private mode the server refuses to send anything to a hosted provider: replies come only from models on your own hardware or the HANNAH server. Chat history stays on your device unless you sign in, which syncs through a database the server's operator chooses.

Actions that change your device or data wait for your approval, and the desktop app enforces its folder and command limits itself, outside the AI model. Read the privacy policy for every kind of data, where it goes and how long it's kept.

Built for integration

An API for chat, agents, voice and tools

Call HANNAH from your own apps through the same server the app uses. Provider keys stay on the server, and every request shares its rate limits and daily budget.

OpenAI-compatible

POST /v1/chat/completions works with any OpenAI SDK and adds HANNAH's routing modes, including Private.

Chat, agents and voice

POST /api/chat and POST /api/agent return replies with emotion metadata and bounded tool calls; POST /api/tts speaks with an optional configured voice.

Agents talking to agents

An MCP server and client, agent-to-agent (A2A) messaging, signed webhooks and a JavaScript SDK.

See API and integrations for examples, or the API integration guide for schemas, environment variables, error codes and production security.

Web, desktop and mobile

Use HANNAH in a browser or install the app

Installers for macOS, Windows, Linux and Android are published with every release, each with a SHA-256 checksum. The desktop and Android packages aren't signed by a store yet, so your system may ask you to confirm the first time. The iOS app builds from source but isn't distributed: that needs Apple signing.

Common questions

About HANNAH

Who makes HANNAH?

HANNAH is built by Harsh Tambade and contributors. The source code is public on GitHub under a source-available, non-commercial license: you can read, run and modify it for personal and non-commercial use.

Does HANNAH work offline?

Yes, with a local model: WebLLM in a browser with WebGPU, or a downloaded model in the Android and iOS apps. The first model download needs an internet connection.

Which languages can I use for voice?

English, Hindi and Marathi. Speech recognition and voices depend on what your browser or operating system provides; Whisper transcription and OpenAI voices work everywhere with a key.

Can HANNAH control my device?

Only through the actions the app offers, and each one asks first. In the desktop app it can work in folders you share and run commands you approve. Seeing the screen and using the mouse (computer use) isn't in the downloadable app yet.

How do I get help?

Open an issue on GitHub. For a security problem, don't post the details publicly: open an issue asking for a private contact.

Is HANNAH a medical or emergency service?

No. HANNAH is software and is not a replacement for emergency services or professional medical, legal, or financial advice.
