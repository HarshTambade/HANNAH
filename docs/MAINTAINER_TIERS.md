# HANNAH Maintainer Tiers

## Core maintainers
- Write access to all modules.
- Release authority.
- Security response ownership.

## Area maintainers
- Ownership of a module or platform.
- Review authority for that area.
- May merge PRs within their area.

## Contributors
- PR-only access.
- No direct write access.
- Must follow contribution guidelines.

## Promotion criteria
- Sustained, high-quality contributions.
- Demonstrated understanding of the module.
- Review and trust from existing maintainers.
